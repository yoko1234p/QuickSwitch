# Security reports

Use this repository's **Security → Report a vulnerability** option for a private report. Include the affected app/version, macOS or browser version, reproduction steps and the impact. A minimal synthetic example is preferred.

Do not post credentials, personal notes, calendar data, real chat media or unredacted logs in public issues. If you have already exposed a credential, revoke it before sharing further diagnostics.

These utilities interact with macOS permissions, selected files, browser pages and optional script extensions. Report unexpected access, unsafe file operations, script execution outside the documented boundary or unintended disclosure of local data. Routine feature requests and non-sensitive bugs belong in Issues.
